# Orientações do professor

Crie um projeto com Angular 22, OptimusUI 2 e Tailwind 4 (CUIDADO COM AS VERSÕES) no repositório Github. Sugiro utilizar os guias de instalação das próprias tecnologias.
- Se quiser utilizar outro framework diferente do Angular, escolha uma biblioteca de componentes para substituir o OptimusUI e adicione o Tailwind em seu projeto.
- Crie um layout bonito para seu projeto, utilizando um tema e componentes do OptimusUI.
- Delegue a estrutura visual da aplicação para o OptimusUI.
- Utilize o Tailwind para ajustes específicos tanto em componentes OptimusUI quanto em elementos html, conforme mostrado em sala de aula.
- Crie operações de listar, detalhar, incluir, alterar e remover de um modelo usando componentes de UI em seu componente de aplicativo.
- Seu modelo deve ter pelo menos 4 atributos: string, number, date e boolean.
- A lista de models pode ser armazenada em memória.
- Envie o link para o repositório para avaliação.

## O que será avaliado?

**A aplicação deve atender as seguintes especificações:**
- A aplicação utiliza Angular 22, OptimusUI 2 e Tailwind 4.
- A aplicação tem um layout bonito.
- Utilizou o tailwind em ajustes específicos de componentes OptimusUI e em elementos html tradicionais.
- A aplicação deve executar e conseguir realizar as operações de listar, detalhar, incluir, alterar e remover o modelo.
- Definiu o model com os 4 atributos indicados.
  
**O aluno deve entender e ser capaz de mostrar em sua aplicação angular:** 

- Os arquivos package.json e package-lock.yaml.
- Os principais arquivos de configuração do angular, das bibliotecas OptimusUI e Tailwind.
- O model utilizado.
- O componente principal que implementa as operações de CRUD.
- O componente principal que utiliza componentes OptimusUI e Tailwind.
- O componente principal que utiliza Data Binding, Diretivas e Eventos de Manipulação de dados.
